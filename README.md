# AXISYMMETRIC SOLAR DYNAMO MODEL - MATLAB



## PURPOSE

---

This program implements a large-scale axisymmetric dynamo model in spherical coordinates. The model evolves the poloidal and toroidal magnetic fields, includes field generation due to differential rotation and the alpha effect, and allows the magnetic force to modify the meridional flow.

The implementation in this folder follows the model described by Sraibman and Minotti (2019). This summary provides a general description of the program and does not replace the full derivation presented in the paper.

## HOW TO RUN

---

1. Open MATLAB and set the current folder to the one containing the program.

2. Run `toy_prueba.m` from the MATLAB Editor or type `toy_prueba` in the command window. The script calls `parameter.m` and the remaining routines, which must stay in the same folder or be included in the MATLAB *path*.

3. The simulation can take a considerable amount of time. The `maxpasos` parameter is initially set to 500000. For a short test, reduce this value in `parameter.m`.

## ORGANIZATION OF THE CALCULATION

---

* `toy_prueba.m` creates the grids, initializes the fields and coordinates the time integration, plot generation, checks and saving of results.

* `parameter.m` defines the physical parameters, the spatial resolution and the output intervals, and prepares the results directory.

* `omegaf.m`, `densidad.m` and `velmeri4.m` compute the rotation, density and imposed meridional flow profiles, respectively.

* `alfan4.m` obtains the kinematic alpha coefficient. `ws1alfaBL1.m` evolves the feedback vorticity and computes the alpha associated with the dynamo.

* `etauv4.m` estimates the local turbulent diffusivity from the flow, the rotation and the magnetic field.

* `calca_1.m` computes the evolution of the poloidal potential `A` and the components `Br` and `Btheta`. `calcanx.m` handles the terms evaluated at the radial boundary.

* `calcb4_1.m` integrates the toroidal field `Bphi`, including the transport, diffusion and shear terms, together with the subgrid closure defined in `Scero3.m`.

* `leap2.m` computes the meridional flow induced by the magnetic force.

* `laplaciano.m`, `suavixy.m`, `suavixy2.m`, `suavixy2d.m` and `suavixy2dbl.m` regularize fields or subgrid terms and apply the symmetries used on the grid.

* `guardaa.m`, `guardab.m`, `guardbb.m`, `guardaur.m` and `guardautit.m` extract and store histories at selected radial indices.

* `creaxyb.m`, `grafico.m`, `graficoa.m` and `grafurut.m` prepare the coordinates and generate diagnostic plots.

## MAIN PARAMETERS

---

The parameter values are defined in `parameter.m`. It is advisable to review this file before starting a long simulation.

* `factalf`: relative amplitude of the alpha effect. Initial value: 0.35.

* `cs`: Smagorinsky coefficient. Initial value: 0.1.

* `suavizado`: interval used to smooth the fields `A` and `B`. Initial value: 200 steps.

* `n`: multiplier of the rotation `omega`. Initial value: 1.

* `dibu`: interval between diagnostic plots. Initial value: 50000 steps.

* `timesave`: sampling interval of the histories. Initial value: 1000 steps.

* `maxpasos`: maximum number of simulation steps. Initial value: 500000 steps.

* `delttime`: initial time step. It is adjusted at the start of the simulation according to the advective and diffusive limits.

* `rtope`: outer radius. Initial value: `7e8 m`.

* `rcero`: inner radius. Initial value: `0.55*rtope`.

* `rp`: radial limit of the imposed flow. Initial value: `0.69*rtope`.

* `lamda`: characteristic length of the subgrid closure. Initial value: `0.1*rcero`.

* `puntostit` and `puntosr`: number of points in the angular and radial resolution, respectively.

* `mu0`: magnetic permeability of vacuum.

* `sigma`: amplitude of the imposed meridional flow.

## OUTPUTS

---

The program prepares a folder whose name includes the values of `factalf`, `cs` and `n`.

At the steps defined by `timesave`, several variables are saved in MATLAB `.mat` files, including `a.mat`, `brtaco.mat`, `btittaco.mat`, `b.mat`, `ur.mat`, `utit.mat` and `todo.mat`.

`.png` files are also generated when the interval defined by `dibu` is reached.

Some auxiliary outputs, such as `alf.mat` and `velmerid.mat`, are saved in the current working folder, according to the `save` statements used in the code.

The histories generated by `guardaa`, `guardab`, `guardbb`, `guardaur` and `guardautit` record angular profiles at certain radial indices. Therefore, these files do not represent a full radial grid.

The `.mat` files can be inspected directly from MATLAB. For example:

```matlab
load('ur.mat')
```

## REQUIREMENTS

---

MATLAB with graphics support is required.

The script uses `findpeaks` to analyze the peaks of a time series. This function requires the **Signal Processing Toolbox**.
